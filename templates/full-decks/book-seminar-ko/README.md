# 한국어 독서 세미나

8장짜리 한국어 기본 틀입니다. 실제 책의 요약이 아니며, 제목·주장·근거·비교·검토·가상 사례·토론·마무리를 자신의 자료로 교체합니다.

생성: bash scripts/new-deck.sh book-talk -t book-seminar-ko

기본 테마는 editorial-serif입니다. T를 누르면 academic-paper와 minimal-white를 비교할 수 있습니다. 모든 페이지에 발표자 노트가 있습니다. S로 발표자 창을 엽니다.

원문 인용과 해설, 발표자가 만든 사례를 구분하세요. 출처는 실제로 확인한 범위만 기재합니다.
