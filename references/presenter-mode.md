# 발표자 화면

발표 화면에서 **S**를 누르면 별도 창이 열립니다. 청중 화면에는 슬라이드만, 발표자 창에는 현재 페이지·다음 페이지·발표자 노트·타이머가 표시됩니다. 팝업 허용이 필요할 수 있습니다.

## 시작점

```bash
bash scripts/new-deck.sh my-talk -t presenter-mode-reveal
```

모든 템플릿에서 런타임과 페이지별 노트만 있으면 사용할 수 있습니다. 한국어 문서는 `<html lang="ko">`로 지정합니다. UI는 ko, en, zh를 구분하고, 알 수 없는 언어는 영어로 표시합니다.

## 노트 작성

```html
<section class="slide" data-title="핵심 질문">
  <h2 class="h2">우리는 무엇을 확인했는가?</h2>
  <aside class="notes">
    <p><strong>확인한 사실</strong>을 먼저 설명합니다.</p>
    <p>아직 불확실한 점을 구분한 뒤 다음 질문으로 넘어갑니다.</p>
  </aside>
</section>
```

화면의 문장을 반복해서 길게 쓰기보다 핵심어, 설명할 예시, 다음 페이지 연결을 기록합니다. 노트의 길이는 실제 발표 시간에 맞춥니다. 한국어 원고에 다른 언어의 글자 수 기준을 그대로 적용하지 않습니다. 출처와 해석 범위도 노트에 남깁니다.

## 조작

- ← →: 페이지 이동. 발표자 창과 청중 창이 동기화됩니다.
- R: 발표자 창 타이머 초기화.
- Esc: 발표자 창 닫기.
- 카드 제목 끌기: 위치 이동.
- 카드 오른쪽 아래 끌기: 크기 조절.
- 배치 초기화: 기본 위치로 복원.
- N: 청중 화면에서 현재 노트를 아래쪽에 표시. 실제 발표 중 청중에게 노트를 보이고 싶지 않으면 S를 사용하세요.

위치와 크기는 덱 경로별로 브라우저에 저장됩니다. 현재·다음 미리보기는 실제 덱의 `?preview=N`을 iframe으로 열어 같은 CSS를 사용합니다. 테마 변경도 미리보기로 전달합니다.

## 점검

각 페이지에 노트가 있는지, 현재와 다음 미리보기가 정확한지, 글자와 버튼이 읽히는지 확인합니다. 브라우저가 BroadcastChannel이나 팝업을 제한하는 환경이라면 실제 발표 환경에서 동기화를 확인합니다. 개인 화면에 두려면 발표자 창을 별도 모니터로 옮깁니다.
